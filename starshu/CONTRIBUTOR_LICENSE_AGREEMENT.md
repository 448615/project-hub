## 一、定义

1.1 **"版权方"** 指 蓝域星河有限公司集团，即本协议覆盖的所有开源项目的合法所有者及版权持有者。

1.2 **"贡献者"** 指向版权方旗下任一开源项目提交贡献的自然人或实体。

1.3 **"贡献"** 指贡献者提交给版权方旗下任一开源项目的任何代码、补丁、文档、设计、数据或其他材料，包括但不限于通过 GitHub Pull Request、Issue 附件、邮件或其他任何形式提交的内容。

1.4 **"项目"** 指版权方旗下以"星海量子"、"StarseaOS"或相关品牌发布的所有开源子项目，包括但不限于：

   - **星枢（starshu，内容运营中枢）**
   - 星舟（starbarge，应用加载器）
   - 星文（starwen，同人创作平台）
   - 星镜（starmirror，相册分享平台）
   - 星铸（starforge，角色卡锻造平台）
   - 后续发布的所有开源模块、工具、库、驱动程序及文档

   （以下简称"项目"或"各项目"）

1.5 **"集团"** 指 蓝域星河有限公司集团及其关联公司。

## 二、版权许可

2.1 贡献者特此授予版权方及其后继者一项 **永久性、全球性、免版税、不可撤销、非排他性** 的**版权许可**（本协议为许可，非版权转让），允许版权方：

   a) 以任何方式使用、复制、修改、分发、合并、出版、展示、表演、传播贡献的全部或部分内容；

   b) 将贡献纳入项目及其衍生作品中；

   c) 将贡献用于 **开源版本**（包括但不限于 AGPLv3、MIT、Apache 等开源许可证）和 **商业闭源版本**（包括但不限于版权方商业产品的专业版、企业版订阅）中；

   d) 将包含贡献的作品以任何许可证形式（包括开源许可证、商业专有许可证）分发，无需另行征得贡献者的同意或支付额外费用。

2.2 贡献者确认，本协议授予的权利包括但不限于版权、专利权及相关知识产权。

3.1 贡献者声明并保证：

## 附录：常见问题

**Q：为什么需要签署 CLA？**

A：本项目采用双许可证模式（开源社区版 + 商业订阅版）。CLA 确保版权方可以将贡献者的代码用于商业版本，同时保护贡献者的权利，实现项目的长期可持续发展。

**Q：CLA 是否意味着我放弃了对贡献的所有权利？**

A：不会。您保留对贡献的所有权，同时授予版权方使用贡献的许可。您仍然可以在其他项目中使用您的贡献。

**Q：我提交的 PR 是否会自动接受 CLA？**

A：提交 PR 即视为您已接受 CLA。如果您不同意 CLA，请不要提交贡献。

**Q：我是代表公司提交贡献，需要特别注意什么？**

A：请确保您已获得公司的书面授权，允许您代表公司提交贡献并接受 CLA。

**Q：本项目涉及认证与权限，贡献时需要注意什么？**

A：请**不要**在 PR 中引入任何削弱安全基线的改动。涉及认证、权限、输入净化、限流的修改必须附带安全影响说明与回归测试。发现安全漏洞请勿公开提交 Issue，请通过邮件私下报告。
