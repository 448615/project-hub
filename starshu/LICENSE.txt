**社区版适用场景**：

- 个人使用（自建博客后台、内部工具）
- 非商业项目
- 开源项目集成
- 学习、研究

**社区版无额外使用限制**：AGPLv3 第 2 条明确 "unlimited permission to run the
unmodified Program"——您可自由部署任意数量实例、对外提供 SaaS 服务

社区版的唯一"义务"是：若您修改了代码并对外分发 / 提供网络服务，
须按 AGPLv3 开源您的修改。

## 我应该选择哪个？

| 使用场景 | 推荐选择 | 原因 |
|----------|----------|------|
| 个人自建后台 / 学习 | 社区版（AGPLv3） | 无开源义务负担 |
| 非商业项目 | 社区版（AGPLv3） | 无开源义务负担 |
| 开源项目集成 | 社区版（AGPLv3） | 与 AGPLv3 开源精神一致 |
| 企业内部单实例 | 社区版（AGPLv3） | 内部使用不分发，无开源义务 |
| 企业内部多实例 | **专业版（推荐）** | 获得官方 SLA 支持 |
| 对外提供 SaaS | **专业版（推荐）** | 获得官方合规审查 + SLA |
| 集成到闭源商业产品 | **专业版（推荐）** | 避免 AGPLv3 §5 传染性 |

> **说明**：AGPLv3 用户可自行多实例部署、SaaS、闭源集成——只要遵守 AGPLv3 开源义务。
> **专业版的真正价值**是：官方技术支持 SLA、闭源集成合规审查、品牌移除服务、
> 商业责任担保。专业版**不是代码功能阉割**，也不改变 AGPLv3 赋予用户的任何权利。

## 与母项目星海量子通用操作系统（StarseaOS）的关系

本组件是星海量子通用操作系统（StarseaOS）的一个**独立子项目**，采用独立于母项目的双许可证模式。

- 母项目星海量子通用操作系统（StarseaOS）采用 **商业专有许可证**，详见母项目根目录的 `LICENSE.txt`。
- 本组件的开源社区版（AGPLv3）**不包含**母项目的任何专有代码。
- 将本组件与母项目结合使用时，**仅限独立进程 / 通过 HTTP API 通信的聚合场景**（聚合体不触发 AGPLv3 传染性，见 AGPLv3 §5 最后一段）。
- **禁止**将本组件源码 import / 链接 / 嵌入母项目形成衍生作品；若确需深度集成，请购买商业订阅（见 `LICENSE.COMMERCIAL.txt`），或改用独立进程 + API 通信方式集成。
- 若违反上述边界，AGPLv3 §5 将要求整个衍生作品以 AGPLv3 开源——这与母项目的专有许可不兼容（AGPLv3 §12 拒绝此类冲突）。
